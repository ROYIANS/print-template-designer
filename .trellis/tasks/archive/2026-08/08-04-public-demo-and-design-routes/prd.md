# 开放访问、演示模式与专业化设计路由

## Goal

移除以 `PTD_ALLOWED_EMAILS` 为入口白名单的封闭访问机制，允许所有通过 GitHub OAuth 的用户试用系统；同时引入管理员身份与可部署的演示模式，在演示部署中展示落地页并周期性将非管理员用户数据恢复为示例状态。将设计、预览等工作区入口拆分为稳定、可分享、接近专业设计工具的资源路由。

## What I already know

- 当前网站使用 GitHub 登录，并额外依赖 `PTD_ALLOWED_EMAILS` 限制可访问邮箱。
- 需要新增管理员邮箱配置；命中的账户视为管理员。
- 需要新增演示模式开关：开启时保留落地页，关闭时根入口只需要登录页。
- 演示模式需要每天定时还原访客示例数据，管理员数据必须排除。
- 演示模式下 `/app` 必须醒目提示当前是演示环境、数据会被定期恢复，并提供 GitHub Fork/Star 横幅入口。
- 现有 GitHub 登录按钮比例失衡、中文断成三行，需要改为与 Foliq 视觉系统一致的横向单行登录动作，并在落地页与简洁登录页复用。
- 设计与预览必须使用不同路由，路由应包含模板资源标识与可读名称，并能承载节点定位等查询参数。

## Requirements

- 删除普通 GitHub 用户的邮箱白名单访问阻断。
- 新增 `PTD_ADMIN_EMAILS`（逗号分隔、规范化邮箱、可选）并提供统一的服务端管理员判定。
- 新增 `PTD_DEMO_MODE=true|false`，并按模式切换公共入口页面。
- 演示模式下以 UTC 自然日为边界，每日 00:00 UTC（北京时间 08:00）恢复非管理员用户的模板与版本数据；不修改用户、OAuth Account、Session 或管理员数据。
- 新访客首次进入工作台时获得同一份确定性的“电价预测周报”示例模板。
- 演示恢复必须幂等，服务重启、并发请求或多实例不得导致同一用户同一天被重复恢复。
- 演示模式下在文件工作台展示醒目的数据恢复提示和 GitHub Fork/Star 横幅；深层设计/预览入口保留不干扰工作的轻量演示标识，允许关闭并在当前浏览器会话中保持关闭。
- 电价预测示例使用显式 A4 纵向 210×297mm 固定纸张合同，所有示例组件边界必须落在实际纸张画布内。
- 重构 GitHub 登录按钮为共享组件：小尺寸 GitHub 图标、单行标签、明确焦点/加载状态；安全说明保持辅助层级。
- 为模板增加不可读、稳定、唯一的资源 key；整数 ID 继续作为内部数据库主键。
- 使用 `/app`、`/design/new`、`/design/:key/:slug`、`/preview/new` 与 `/preview/:key/:slug` 拆分文件、设计和预览入口。
- key 是资源定位依据，slug 只提供可读性；错误 slug 在模板载入后替换为规范地址。
- 设计与预览共享同一个已挂载文档控制器，SPA 内切换时保留未保存内容；直接刷新预览链接加载服务端已保存版本。
- 兼容 `/app?new=blank` 与 `/app?template=<integer>` 历史入口，并保持所有读取的 `ownerId` 授权校验。

- [x] 配置的管理员邮箱在服务端被一致识别为管理员。
- [x] 演示模式开启时显示落地页；关闭时公共根入口进入登录体验。
- [x] 新访客获得电价预测示例；每日恢复只重置非管理员模板/版本，并保留身份、会话和管理员数据。
- [x] 同一访客同一 UTC 日并发触发恢复时只执行一次。
- [x] 演示模式下 `/app` 明确告知数据恢复策略并能跳转到项目 GitHub；非演示模式不渲染该提示。
- [x] 设计/预览内的紧凑演示提示可关闭，刷新和切换 surface 后在当前浏览器会话内不再遮挡内容。
- [x] 电价预测示例的纸张尺寸、方向和内容坐标匹配，不产生越界裁切。
- [x] GitHub 登录按钮在桌面与移动端均保持单行、比例协调、键盘焦点清晰，并被演示落地页和非演示登录页共同使用。
- [x] 设计与预览拥有不同、可直接访问且可刷新的规范 URL；SPA 内互相切换保留当前编辑内容。
- [x] 历史 `/app` 查询参数入口迁移到新路由。
- [x] 相关单元/集成测试、lint、typecheck 通过。

- Lint / typecheck / CI green

## Out of Scope (explicit)

- 新增 GitHub 以外的身份提供商。
- 多角色 RBAC 管理后台。
- 多租户组织权限体系。
- 任意 Cron 平台的远程自动配置；仅提供项目内可运行、可部署的调度入口。
- 通过 URL key 向未登录用户公开模板或新增分享权限。
- 服务端自动保存、多人协作或跨浏览器同步未保存草稿。

## Technical Approach

- 访问配置集中由服务端解析；`/api/runtime` 暴露非敏感的 `demoMode`，`/api/account/me` 暴露当前账户的 `isAdmin`。
- Prisma 增加 `Template.key` 与 `DemoUserState`。每日状态行与模板重建位于同一事务，以数据库唯一键作为幂等边界。
- Auth Guard 在演示模式下确保非管理员访客已完成当天恢复，普通模式没有额外数据库写入。
- Web 路由解析使用纯函数和显式 union；模板 API 同时支持按 key 读取和既有整数 ID 写入。
- `/design` 与 `/preview` 渲染同一文档工作区组件的不同 surface，避免路由切换丢失 React 内存状态。

## Decision (ADR-lite)

**Context**：当前顺序整数模板 ID 不适合作为专业 URL，预览又是编辑器内覆盖层；演示恢复如果删除身份数据会使 OAuth Session 失效，多实例定时器也可能重复写入。

**Decision**：增加模板 opaque key 与装饰性 slug；设计和预览共享文档控制器。演示恢复仅重建访客模板，通过每用户每日状态行幂等执行，固定使用 UTC 日界线。

**Consequences**：需要一次 Prisma 迁移及前后端契约更新；现有整数 API 可保留，迁移风险较低。未保存草稿只在当前 SPA 生命周期内保留，刷新预览只显示最近保存版本。
