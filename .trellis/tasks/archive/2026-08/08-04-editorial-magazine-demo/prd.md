# 创建中文杂志排版演示模板

## Goal

创建一份可直接导入 Foliq 设计器的专业中文杂志排版 Demo JSON，用于展示多页编辑出版物、复杂文字层级、图文混排与稳定 PDF 输出能力。视觉参考用户提供的留白型文化杂志内页，但形成独立的原创设计与文章内容。

## Design Context

- **目标受众**：评估 Foliq 排版能力的潜在用户、设计师及产品演示观众。
- **使用场景**：直接导入设计器，查看、编辑、预览并导出成 PDF，作为复杂排版能力展示样例。
- **品牌语气**：克制、文学、编辑感强，接近当代中文人文杂志；避免商务驾驶舱、通用卡片和模板化 AI 视觉。

## Requirements

- 使用大 16 开（大度）竖版固定布局，共 4 页，纸张精确为 210 × 285mm，内容填满安全可打印区域。
- 主题为原创人文专题《夜读城市：独立书店如何保存一座城的时间》。
- 使用暖白纸张与纯黑、深灰、浅灰构成黑白杂志，不使用彩色强调色。
- 标题使用 `Noto Serif SC` / 思源宋体回退并加粗；正文使用宋体；引文使用楷体。
- 版式以连续文章阅读为核心：开篇页、长文页、跨栏黑白图片、图注、首字下沉、一个楷体引文与收束页。
- 正文总量约 5,000–6,000 个中文字符，形成一篇连贯专题文章，而不是多个零散信息模块。
- 每个正文栏尽量由一个连续长文组件承载多个自然段；减少标题、编号、卡片、列表和互不相干的小文本块。
- 正文与引用文本应为可编辑组件，不把文字烘焙进图片。
- 文章正文原创，避免复制受版权保护的网络文章。
- 选用 2 张可公开访问并适合杂志主题的网络图片；转换为黑白后以 data URL 嵌入模板，避免输出阶段远程资源阻断。
- 图片下方写明来源与许可/出处信息。
- 不使用二维码、条码或动态代码组件，避免为杂志样例引入不必要的输出依赖。
- JSON 文件放入 `examples/`，文件名清晰、可直接导入。

## Acceptance Criteria

- [x] Web 端真实 `parseTemplateJson` 能解析模板。
- [x] 页面配置为 custom 大 16 开竖版，精确为 210 × 285mm。
- [x] 模板包含 4 页；正文组件按连续栏组织，不以组件数量作为复杂度目标。
- [x] 包含 2 张黑白嵌入式图片，所有 `RoyImage` 均使用 data URL。
- [x] 原创正文约 5,000–6,000 个中文字符，段落阅读顺序明确且跨栏衔接自然。
- [x] 正文字体为宋体族，引文字体为楷体族，标题为加粗 Noto Serif SC/思源宋体族。
- [x] Chromium 输出诊断为空，不出现 `REMOTE_RESOURCE_BLOCKED`、`IMAGE_RENDER_FAILED`、`LAYOUT_TIMEOUT` 或 `TEXT_OVERFLOW`。
- [x] 导出的 PDF 为 4 页 210 × 285mm，页眉、页码、图注和底部内容均完整。
- [x] Poppler 渲染后逐页视觉检查通过：无裁切、重叠、断行异常或明显空洞。

最终模板包含 74 个组件、9 个连续正文栏、2 张灰度嵌入图片和 5,173 个中文正文字符。第二页由三条窄栏调整为两条长栏，并缩短图片高度，将版心空间优先留给连续文章阅读。

## Definition of Done

- JSON 已格式化并可直接导入。
- 真实导入解析、Chromium PDF 导出和逐页图片渲染均验证通过。
- 任务 PRD 记录最终设计和技术约束。
- 不修改或提交工作区中已有的无关 Demo/tmp 文件。

## Technical Approach

- 复用当前模板交换格式：`_version + pageConfig + pages[].componentData + data`。
- 使用 `RoySimpleText`、`RoyText`、`RoyImage`、`RoyRect`、`RoyLine` 和 `RoyCircle` 组合版面。
- 采用项目逻辑像素坐标，大 16 开画布按 1050 × 1425px 设计；左右主安全边距约 50px。
- 正文采用两栏或三栏连续网格，每栏只设置少量长文本组件；章节层级服从阅读流而不是展示模块数量。
- 使用生成脚本机械构造组件、嵌入压缩图片并输出格式化 JSON，降低手写 ID 和坐标错误。
- 通过现有 Web 解析器与 Chromium 输出链路进行端到端验证。

## Decision (ADR-lite)

**Context**：远程图片在打印预览和 PDF 输出阶段会被输出契约主动阻止；杂志排版又高度依赖图片稳定性。

**Decision**：仅在研究阶段从公开网络来源获取图片，转换为灰度后生成 data URL 嵌入；正文采用 5,000–6,000 字原创长文，并以连续栏为主要排版结构。

**Consequences**：JSON 文件体积会增大，但导入、预览和导出具备确定性，不依赖第三方站点可用性或跨域策略。

## Out of Scope

- 不增加新的设计器组件或修改编辑器运行时代码。
- 不实现自动文字绕图、跨页文本流或印刷出血/裁切标记。
- 不提供真实出版文章的全文转载。
- 本轮不自动提交或归档任务，除非用户另行要求。

## Technical Notes

- 参考图强调高留白、细线页眉和窄栏长文；本模板保留这些编辑特征，并主动减少模块化切割。
- 当前导出器要求图片使用嵌入资源，否则会报告 `REMOTE_RESOURCE_BLOCKED`。
- 现有多页输出链路已验证物理视口/逻辑画布结构；本任务使用 custom 210 × 285mm 纸张验证同一契约。
