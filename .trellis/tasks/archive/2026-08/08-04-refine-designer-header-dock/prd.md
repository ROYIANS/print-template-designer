# 收敛设计器头部与底部工具栏

## Goal

在不改变设计器既有功能和整体视觉语言的前提下，降低 header 账户入口与底部上下文工具条的视觉重量，收紧相关操作之间的空间关系，让主工具 Dock 保持最明确的视觉焦点。

## Requirements

- Header 右侧账户入口仅显示圆形头像，移除昵称和下拉箭头；点击头像仍打开原有账户下拉菜单。
- 将“文件工作台”“保存模板”和头像组成更紧凑的右侧操作组，减少按钮与头像之间的空白。
- 底部主工具 Dock 按内容自适应宽度，移除造成两侧空余的固定宽度，同时保留居中悬浮和紧凑模式行为。
- 底部附属灰色上下文工具条缩小按钮尺寸，保持适当的上下内边距。
- 附属工具条按钮激活态使用比工具条背景更深的中性灰，不使用品牌主色；下方主 Dock 的激活态保持主色，用视觉层级区分上下两层。
- 保留现有 hover、focus、disabled、键盘和下拉菜单交互语义。
- 根工作区增加 `dev:all` 命令，在沿用 `dev:web` 的依赖预构建顺序后，同时启动四个前端包 watcher、Web 与 Server；Server 提供统一的 `dev` 脚本入口供 workspace 并行调度。
- 根开发脚本递归调用包管理器时统一使用 `corepack pnpm`，避免全局旧版 pnpm 接管并触发 engine 拒绝。
- 提供一份可导入的售电行业专业复杂报表示例模板，主题为电价预测与交易风险；模板纸张与实际内容比例匹配，采用 A5 纵向，并让主体内容占满页面可打印安全宽度。
- 示例模板必须通过真实打印预览和 PDF 导出，不能包含 `QRCODE_RENDER_FAILED`、`LAYOUT_TIMEOUT`、越界裁切或额外空白页。

## Acceptance Criteria

- [x] Header 账户触发器只渲染圆形头像，不显示昵称或下拉图标，并有明确的无障碍名称。
- [x] 点击头像仍能打开账户菜单，现有账户菜单功能和测试保持通过。
- [x] Header 右侧三个操作的间距在常规和紧凑宽度下均明显收紧且不重叠。
- [x] 主工具 Dock 宽度由内容决定，无固定 448px 宽度或同类多余左右留白。
- [x] 上下文工具条按钮相较主 Dock 按钮更小，工具条仍保留均衡的垂直内边距。
- [x] 上下文工具条激活项使用深灰背景且可清晰辨识，不出现品牌主色背景。
- [x] 相关单元测试、前端 lint、类型检查通过。
- [x] `corepack pnpm dev:all` 可从根目录同时调度 Web、Server 与前端 workspace watcher，且不会跳过前端依赖预构建。
- [x] 售电行业报表示例可直接导入，覆盖预测均价、MAPE、合约覆盖、组合毛利、区域价格暴露、风险热力矩阵与模型回测；A5 纵向页面与内容比例协调，主体横向覆盖页面安全宽度且所有页脚位于页面边界内。
- [x] 示例模板通过真实 Chromium PDF 导出；逐页渲染后无二维码失败、布局超时、裁切、重叠或空白页。

## Definition of Done

- 实现和视觉契约测试同步更新。
- 使用项目本地二进制完成 lint、类型检查与相关测试。
- 不安装依赖、不修改 lockfile、不触碰用户已有的未跟踪文件。
- 复核是否产生值得写回 `.trellis/spec/` 的新项目约定。

## Technical Approach

- 复用现有账户菜单状态与内容，只收敛触发器结构和样式。
- 在 `@ptd/react-designer` 的 AppBar、FloatingToolDock 与上下文 Toolbar CSS Module 内做局部样式调整。
- 更新现有视觉契约测试，使断言描述新的自适应宽度和中性激活态，而非引入截图快照或新依赖。
- 修复 `RoyQRCode` / `RoyBarCode` 在父类构造期间首次异步渲染时，子类字段初始化覆盖 render session 的时序问题；使用类外 `WeakMap` 会话保证 stale callback 防护在首次渲染、更新和销毁阶段一致。
- 将演示报表从不匹配的 A4 纵向改为 A5 纵向，按 A5 逻辑画布重新居中全部横向几何，并收回页脚和审批追溯区，确保正文占满安全宽度且不越过页面底边。

## Decision (ADR-lite)

**Context**: 截图中 header 账户入口被做成了完整按钮，底部两层工具条也同时使用品牌强调色，造成右侧操作松散、上下工具层级互相竞争。

**Decision**: 采用“克制的专业工具界面”方向：头像作为轻量菜单触发器，相关 header 操作紧密成组；附属工具条只使用中性色表达选中状态，品牌主色留给主 Dock。

**Consequences**: 界面层级更清晰且功能不变；头像入口需要依靠 tooltip/ARIA 名称补足文字标签被移除后的可发现性。

## Out of Scope

- 不重做 header 左侧品牌、菜单或整体配色。
- 不修改账户菜单内容、认证逻辑、保存/打开行为。
- 不调整左侧资源栏、右侧属性面板、画布或状态栏。
- 不增加动画、依赖或新的全局设计令牌，除非现有令牌不足以表达中性激活态。
- 不改变数据库迁移、Server 环境变量或服务启动语义。

## Technical Notes

- 目标用户是持续编辑结构化打印模板的专业/高频用户；当前任务强调操作密度、层级和可发现性，不改变产品定位。
- 品牌气质沿用现有 Foliq 工具型界面：专业、克制、深色主工具区与浅色工作区形成层次。
- 设计依据来自用户提供的当前界面截图及四项明确反馈。
- 适用规范：`.trellis/spec/monorepo/styling-conventions.md`、`ptd-ui-system.md`、`typescript-conventions.md`、`quality-guidelines.md`。
