# 工具坞组件选择器与素材入口重构

## 背景

当前 Designer 把完整组件目录放在常驻资源面板中。用户为了切换一个画布创作工具，需要先打开
280px 宽的“组件”面板，再在目录中寻找组件。这把短暂的工具选择动作错误地建模成了资源浏览，
同时让真正应该长期存在的素材、页面、图层和数据资源共享同一入口。

本任务将“选择组件工具”和“管理可复用素材”拆成两个明确模型：组件工具通过 Tool Dock 下方的
紧凑 Picker 选择；原“组件”资源面板改为“素材”面板，为后续图片、Logo、印章、SVG 与服务端
资产库保留正确的信息架构。

## 目标用户与场景

- 目标用户是连续使用桌面浏览器工作的报表开发者、实施人员和版面设计师。
- 用户需要快速在选择、抓手、文本、图形、图片、表格、二维码和条形码工具之间切换。
- 用户需要保持画布空间，不应为了换一个工具长期展开完整目录。
- 触屏、小尺寸容器和键盘用户必须拥有与鼠标等价、可预测的选择路径。

## 设计方向

保持 PTD“精密、轻快、可信”的数字印前工作台气质：紧凑、平面、冷纸白、蓝石墨与克制钴蓝。
Picker 是临时工具浮层，不是 SaaS 卡片、Modal 或第二个资源侧栏；结构、细线、稳定对齐和明确状态
承担视觉层级。

## 功能范围

### 1. Tool Dock

工具区固定为：

1. 选择工具。
2. 抓手工具。
3. 文本工具组：简单文本与富文本，主按钮使用本实例最近选择的文本工具。
4. 图形工具组：继续使用当前最近图形与连续绘制合同。
5. 图片工具。
6. 自由表格工具。
7. “更多组件”按钮。

工具位置稳定，不根据最近使用动态重排。二维码和条形码默认进入“更多组件”。

### 2. 更多组件 Picker

- 点击 `···` 在 Tool Dock 右侧打开非模态 Portal 浮层，不改变 Resource Panel 开合。
- 浮层只展示 `kind: available` 的真实可创作组件，不展示 planned 项和伪命令。
- 顶部提供标题、可见搜索语义和关闭按钮。
- 显示本 Designer 实例最近从 Picker 使用的最多 4 个组件；没有最近项时不显示该区。
- 其余组件按文本、表格、图像、编码、图形分组，以紧凑二列工具行呈现。
- 搜索匹配现有 Catalog 名称、描述、关键词和技术类型；无结果时提供恢复动作。
- 当前有效工具同时使用图标/对勾与轻量 surface 表达，不能只依赖颜色。
- 选择组件后激活现有 draw tool、记录最近使用并关闭 Picker；不得立即创建 Schema。
- One-shot、Shape 连续绘制、文本创建后编辑、QR 正方形等既有合同保持不变。
- Picker 的打开、搜索和最近使用均为实例级 UI 状态，不进入 `TemplateSchema`、历史或 Host 变更。

### 3. 键盘、焦点与输入方式

- 打开后聚焦搜索框；Tab 可遍历组件与关闭动作。
- 组件网格支持 Arrow/Home/End 移动焦点，Enter/Space 选择，Escape 关闭并恢复触发按钮焦点。
- Portal 声明 `data-ptd-editor-interactive`，Designer 根级指针与快捷键不得抢占交互。
- 鼠标在浮层外按下可 light-dismiss。
- Touch/Pen 外部 pointerdown 不关闭 Picker，避免轻触误关；触屏通过关闭按钮、选择组件或 Escape
  明确关闭。
- 浮层根据 Designer 容器、Trigger 和自身尺寸定位并 clamp，不能被浏览器或嵌入式 Designer 边界
  裁切；窗口 resize、滚动和容器尺寸变化时重新定位。

### 4. 素材资源面板

- `ResourcePanelId` 从 `components` 改为 `assets`，入口标签为“素材”。
- 宽屏首次打开的默认资源面板改为“页面”，避免空素材面板占据主工作空间。
- 第一版素材面板明确说明尚未收集可复用素材，并提供一个真实可执行的“绘制图片框”动作；该动作
  激活 `RoyImage` 工具并关闭/保留面板行为遵循当前模式。
- 不创建仅存于内存、刷新即丢失的伪资产库，不伪造上传、收藏、文件夹或服务端同步。
- 后续资产任务再定义模板资产引用、去重、持久化、对象存储和权限合同。

### 5. 文案与稳定入口

- 原“组件面板”相关提示改成“更多组件”或“素材”。
- 稳定区域从 `data-ptd-region="component-panel"` 更新为
  `data-ptd-region="asset-panel"`。
- 更新 UI Spec、React Designer README 和测试，记录新的工具/资源边界。

### 6. 形状创建反馈

- 新建直线、矩形、椭圆和星形必须立即可见，不能依赖选中框证明创建成功。
- 直线默认使用 2px 蓝石墨填充；矩形和椭圆默认透明填充、1px 蓝石墨实线描边；星形默认使用
  蓝石墨填充。
- 默认形状保持适合报表边框、分区和标记的克制中性色，不使用大面积主题钴蓝。
- 修改 Core Registry 的 canonical defaults；Renderer 和 Designer Factory 继续消费同一份默认值。
- 星形 Renderer 使用包内自包含 SVG，不依赖宿主额外加载 Remix Icon 字体或其他图标字体。

### 7. 图片异步渲染回归

- 图片的 empty、loading、ready、error 四态必须互斥，状态切换时不得把旧图片与新状态节点并排保留。
- 图片地址更新后，旧请求的迟到 load/error 回调不得覆盖新地址；组件销毁后异步回调不得继续更新 DOM。
- loading 阶段在离屏图片节点中完成载入，Frame 内只呈现当前状态；ready 后只保留当前图片。

## 非目标

- 不实现服务端资产库、上传队列、对象存储、素材文件夹、收藏或权限。
- 不改变组件 Schema 结构、绘制几何或历史模型；仅调整 Core Registry 的 canonical 创建默认值。
- 不新增视觉型 UI 框架或 Popover 依赖。
- 不让 planned Catalog 项进入可交互 Picker。
- 不在本任务实现数据绑定、表达式或自动分页。

## 验收标准

1. Dock 常驻选择、抓手、文本组、图形组、图片、自由表格和更多按钮，所有位置稳定。
2. 简单文本/富文本可从文本组切换；主按钮复用本实例最近文本工具。
3. Picker 可以搜索并选择全部 10 个可用组件，planned 项不会出现。
4. 选择 Picker 项只激活工具，不创建组件；完成拖框后的既有一次性/连续行为不回归。
5. Picker 支持键盘导航、焦点恢复、鼠标外部关闭和触屏防误关。
6. 1600×1000、1366×768、1024×768 与手机宽度下浮层不被主要边界裁切。
7. 原组件资源入口变为素材，宽屏默认显示页面面板，素材空态动作真实可用。
8. 没有 Schema、Host emission 或历史污染。
9. 新建直线、矩形、椭圆和星形无需选中即可看见，且默认样式由 Core Registry 统一提供。
10. 图片地址更新期间不会同时显示旧图与 loading/error 状态，迟到回调不会覆盖当前图片。
11. TypeScript、Vitest、ESLint、Prettier、React Designer 包构建与 Web 生产构建通过。

## 人工验证矩阵

- 精细指针：打开、搜索、切换分组项、外部关闭、当前工具状态。
- 键盘：Tab、Arrow、Home、End、Enter、Space、Escape 与焦点恢复。
- 粗指针：外部轻触不误关、关闭按钮和组件选择可关闭。
- 响应式：wide / standard / compact、窄手机、200% 浏览器缩放。
- 工具回归：文本创建后编辑、图片/表格一次创建回 Select、Shape 连续绘制、Space 临时 Hand。
- 媒体回归：已有图片切换地址时只显示当前 loading，成功后只显示新图，失败时只显示错误状态。
