# Canvas-first 工作台 UI 收官改造

## 背景

当前 `@ptd/react-designer` 已具备稳定的纸张画布、组件创建与变换、属性编辑、历史、图层、
真实毫米标尺和多色参考线，但工作区外壳仍延续 Legacy 的“顶部双工具栏 + 五入口 Rail + 固定左右
面板”结构。PR4-A 引入了 Workshop/Zed 启发的视觉语言，却没有根本改变命令分层和空间模型：
组件目录长期占据左侧、右侧空态持续占宽、Command Bar 同时陈列大量无关或禁用命令，窄视口只能
直接隐藏面板。

用户确认 PTD 首先服务于自己：一个同时承担报表开发与版式设计的制作者。产品目标是具有
InDesign 精神、数据原生且适合桌面浏览器连续工作的专业报表设计器。本任务是 UI 阶段的收官
任务；完成后，项目转向数据源、导出、多页与服务端等功能阶段。

## 设计上下文

### 首要用户

- 同时理解数据字段、表达式、分页规则和精确版式的报表制作者。
- 在设计与开发工作流之间频繁往返，而不是固定属于单一角色。
- 主要使用桌面浏览器、键盘和精细指针；触屏与浏览器放大仍需可操作。

### 核心工作流

1. 设置纸张与打印参数。
2. 创建文本、图片、表格、条码、二维码、形状与容器。
3. 使用图层、属性、标尺和参考线完成精确排版。
4. 浏览数据字段并把数据能力交给后续阶段扩展。
5. 预览、保存、导出，并在未来使用数据校样能力检查分页与溢出。

### 品牌与交互语气

**Canvas-first Industrial Editorial**：冷静、精密、数据原生、纸张优先。专业感来自稳定的空间
关系、真实测量、上下文命令、可折叠面板和键盘操作，不来自装饰、卡片堆叠、大面积品牌色或
旧式 Ribbon。

## 目标

1. 把工作区重构为文档栏、上下文栏、工具 Dock、按需资源面板、主画布、属性检查器和测量状态栏。
2. 最大化主画布，并让 1600、1366、1024 三档宽度采用不同但完整的工作区策略。
3. 把现有命令迁移到符合心智模型的位置，不删除已经实现的编辑能力。
4. 让未选择组件时的 Inspector 显示真实页面属性，而不是浪费空间的空状态。
5. 面板开合、活动资源、面板宽度等保持实例隔离，且不写入 `TemplateSchema` 或模板历史。
6. 为后续数据绑定和数据校样阶段提供明确但不虚假的扩展位置。

## 非目标

- 不实现数据绑定、表达式编辑器、数据样例切换或数据校样 Dock 的业务逻辑。
- 不实现组件吸附、自定义标尺原点、母版页、多页增删或分页算法。
- 不实现新的导出、保存、服务端或协作能力。
- 不重写 Canvas、ComponentAdjuster、组件 Schema、历史或现有参考线模型。
- 不引入完整 UI 框架、布局框架、Tailwind、CSS-in-JS 或新图标体系。
- 不为了填满新区域添加无效按钮、伪状态、假数据或不可执行的菜单项。

## 信息架构

### 文档栏（36px）

- 左侧：当前 Legacy Logo、`PTD` 字标、可在宽度不足时折叠的产品名。
- 中间：模板标题、页面规格和本地编辑状态。
- 右侧：载入、预览入口（仅在有真实行为时展示）、保存等文档级动作。
- 撤销/重做可作为紧凑的文档历史动作保留；不在此放组件、排列、标尺或缩放命令。

### 上下文栏（40px）

- 无组件选择：页面方向、标尺、参考线和当前页面高频设置。
- 单选：几何摘要与组件高频动作；保持锁定、层级和删除可发现。
- 多选：对齐、分布、组合和批量动作。
- 选中参考线：位置、颜色、显隐、锁定和删除相关命令。
- 无关命令按上下文移除，而不是长期显示为整排禁用图标。
- 所有现有命令仍有按钮、快捷键、Quick Bar、图层面板或 Inspector 中至少一个可达入口。

### 工具 Dock（44px）

- 永久工具：选择、文本、图片、表格、条码/二维码、形状、容器、数据资源入口。
- 高频创建工具点击后使用现有 Catalog/Factory 在纸张可见区域创建真实组件。
- 同类低频工具可通过资源面板发现；本任务不实现复杂 flyout 或持久绘制模式。
- 工具按钮使用 Remix Icon、Tooltip、快捷提示和 `aria-label`；细指针视觉密度与粗指针命中区分离。

### 左资源面板（默认 220px，可折叠、可调整）

- `页面`：显示真实页面列表和当前页；本任务不添加多页结构命令。
- `图层`：复用现有组件层级、选择和锁定状态。
- `数据`：复用真实 `dataSource` 字段列表，明确后续绑定阶段，不伪造编辑能力。
- `资产`：承载完整 Component Catalog、搜索、点击创建和拖拽创建。
- 重复点击活动 Dock 入口折叠面板；切换入口不会改变画布选择。
- 桌面宽度允许拖动调整，并限制在安全范围内。

### 右侧 Inspector（默认 304px，可折叠、可调整）

- 单选和多选继续使用现有真实属性编辑能力。
- 未选择组件时显示 Page Inspector：页面规格、方向、尺寸、边距、背景、默认字体和标尺状态。
- 只开放 Store 已能可靠修改的页面字段；其余信息使用真实只读摘要，不伪造提交。
- 面板标题、分区、数值输入和滚动仍遵守 PTD Panel/Form 合同。

### Canvas

- 复用现有纸张、组件、选择、标尺、参考线和滚动模型。
- 缩小外围固定留白，并为 Fit Page/视口适配保留后续接口。
- 面板开合和调整宽度时，不修改 `scale`、组件几何或模板历史。
- Canvas viewport 始终是唯一主滚动容器。

### 状态栏（24px）

- 左侧：选择状态和当前页。
- 中部：页面物理尺寸、单位、参考线/锁定等真实编辑状态。
- 右侧：缩放控制和本地编辑状态。
- 缩放从旧 Command Bar 迁移到底部，并保持 50%–200% 现有能力。
- 数据校样入口仅在真实数据校样能力实现后出现，本任务不展示假错误数。

## 响应式合同

### 宽工作区（容器宽度 >= 1440px）

- Tool Dock、220px 左资源面板、主画布和 304px Inspector 同时显示。
- 左右面板均可折叠和拖动调整。
- 1600×1000 下 A4 100% 页面与标尺应完整可读。

### 标准工作区（1180–1439px）

- Tool Dock 与 Inspector 保持；左资源面板默认折叠或以用户状态为准。
- 打开左资源面板时不得使上下文栏与 Inspector 重叠。
- 1366×768 下 Canvas 仍为视觉主区域。

### 紧凑工作区（< 1180px）

- Tool Dock 保持。
- 左资源面板和 Inspector 作为互斥 overlay panel 打开，不能永久同时压缩 Canvas。
- 1024×768 下能够创建/选择组件、打开任一面板、编辑属性并使用标尺。
- Escape 关闭当前 overlay；焦点、滚动和可点击区域不能落在不可见面板内。

### 输入与浏览器缩放

- `pointer: coarse` 时关键命中区至少 40px。
- 浏览器 200% 缩放时，文档动作和上下文动作通过折叠/溢出保持可达，不产生不可达横向命令。
- 不使用设备检测；外壳响应使用 Designer 容器宽度或其等价可靠测量。

## UI 状态与技术边界

- 工作区 UI 状态由每个 `<Designer>` 实例拥有，不放在模块全局，也不写入 `TemplateSchema`。
- 至少包含：活动资源面板、左面板开合、Inspector 开合、左右面板宽度和紧凑 overlay 状态。
- 面板 resize 使用 CSS Custom Properties 表达动态宽度；静态颜色、间距和尺寸仍由 token/CSS Module 管理。
- 面板手势必须清理 document 事件；锁定最小/最大宽度，避免拖出不可恢复状态。
- 保留并扩展稳定 `data-ptd-region`，不得依赖 CSS Module 类名作为宿主定制 API。
- 不改变受控 `<Designer>` props、模板回传语义或包样式入口。

## 命令迁移要求

| 现有命令       | 新位置                                          |
| -------------- | ----------------------------------------------- |
| 撤销/重做      | 文档栏或上下文栏紧凑历史组 + 快捷键             |
| 复制/剪切/粘贴 | 快捷键；相关对象动作保留在 Quick Bar/上下文入口 |
| 删除           | Delete、Quick Bar、上下文栏                     |
| 锁定           | Quick Bar、图层、上下文栏、Inspector            |
| 层级           | Quick Bar、图层或上下文栏                       |
| 对齐/分布      | 多选上下文栏                                    |
| 组合/拆分      | 多选/组合上下文栏                               |
| 页面方向       | 页面上下文栏与 Page Inspector                   |
| 标尺/参考线    | 页面或参考线上下文栏                            |
| 缩放           | 状态栏                                          |
| 保存/载入      | 文档栏                                          |

## 可访问性

- 所有图标按钮有 `aria-label`、Tooltip、focus-visible 和 disabled/pressed 状态。
- Dock/Tab 使用 Radix roving tabindex 或等价正确键盘模型。
- 拖拽创建和面板 resize 均有点击或按钮替代路径。
- 面板折叠按钮表达当前状态，不仅依赖图标方向。
- overlay 打开后 Escape 可关闭；不可见内容不参与键盘导航。
- 动效遵守 reduced-motion，不动画 width/height。

## 验收标准

### 功能保真

- [x] 现有组件点击/拖拽创建、选中、框选、移动、缩放、旋转保持正常。
- [x] 撤销/重做、复制/粘贴、删除、锁定、层级、对齐、分布、组合/拆分仍可达并工作。
- [x] Property Inspector 的单选、多选、锁定与历史手势合同保持。
- [x] 保存、载入、标尺、参考线、横竖纸张和 50%–200% 缩放保持。
- [x] 标尺 Hover 显示临时参考线和实时毫米位置，点击才固定；固定参考线 Hover 可读取位置。
- [x] 框选覆盖层不遮挡组件，并能在 Canvas viewport 边缘自动滚动、跨屏连续追随指针。
- [x] 未激活组件常态无边界；Hover 显示淡主色虚线与透明蒙版，编辑边界不占用组件盒模型。
- [x] 无选择时 Page Inspector 展示真实页面信息，并能执行约定的真实设置。

### 布局与响应式

- [x] 1600×1000：双面板工作模式，A4 100% 可读，无工具重叠。
- [x] 1366×768：左资源面板可折叠，Canvas 是主区域。
- [x] 1024×768：左右面板作为可关闭 overlay，关键能力完整。
- [x] 面板可折叠、可调整宽度；重新打开不会越界或丢失活动面板。
- [x] 浏览器 100%/200%、画布 50%/75%/100%/150% 完成检查。

### 质量

- [x] TypeScript、Vitest、ESLint、`@ptd/react-designer` build 和 Web build 通过。
- [x] CSS Module 映射非空；不提交 `dist`。
- [x] 无 `!important`、`as any`、`@ts-ignore`、静态 JSX 颜色、magic z-index 或无语义装饰。
- [x] 交互控件具备 default、hover、focus-visible、active、disabled；异步载入具备 loading。
- [x] 真实浏览器截图覆盖无选择、单选、多选、锁定、面板折叠、滚动和紧凑 overlay。
- [x] 旧 UI 布局合同更新为 Canvas-first 合同，任务研究和实现决策全部落盘。

## 实施切片

1. Workspace UI state、面板开合/宽度和响应式基础。

3. Tool Dock 与 Pages/Layers/Data/Assets 资源面板。
4. Context Bar 与现有命令迁移。
5. Page Inspector、右 Inspector 折叠与状态栏缩放。
6. 三档布局、键盘/粗指针和视觉细化。
7. 完整回归、规范更新和收官提交。
