# Supply ASCII Hero 参考研究

## 来源

- 用户提供的本地快照：仓库根目录 `supply-demo.html`
- 页面来源可由快照中的 `hello@frontend.supply` 确认为 `frontend.supply`
- 研究日期：2026-07-31

该文件是只读视觉参考，不属于产品源码，也不得提交 `supply-demo.html` 本身。

## 实际实现

参考页没有使用 Three.js、WebGL 或 Canvas。Hero 由两层 DOM ASCII 文本组成：

1. 背景层使用 `.,':;~-\`` 等低密度字符构造噪声场；
2. 前景层使用 `&_=!#$@%01` 等高密度字符，根据预生成亮度图构造可识别主体。

背景层大约每 80ms 重算一次，密度随纵向位置按约 `y^2.5` 墠长，所以顶部自然留白、底部逐渐变密。
首次加载时可见行从底部向上增加，形成字符噪声“长出”的过程。

前景层同样大约每 80ms 重算字符映射，使轮廓与表面密度持续轻微闪烁；整个前景主体再以约 40 秒一圈
的线性速度缓慢旋转。参考实现本身不响应鼠标，两层都不接收 pointer event。

## 对 PTD 的转译

PTD 不复制参考页的品牌图形或亮度图，只复用其构图机制：

- 背景：底部聚集的稀疏标点噪声，首次从底向上显现；
- 前景：第一眼可辨识的三张错位纸张、排版线和中央套准标记；
- 动态：字符密度轻微闪动，前景约 40–48 秒匀速旋转；
- 交互：只允许小幅视差，不再使用磁场形变或透视波浪；
- 性能：离开视口或页面进入后台时暂停；
- 可访问性：`prefers-reduced-motion` 下输出完整静态帧，不旋转、不持续重算。

## 否决项

此前 PTD 使用 Canvas 2D 绘制透视波浪、纸张区域与鼠标磁场。它虽然有交互，但缺少明确主体，第一眼
更像通用粒子地形，用户已明确认为效果不好。后续不继续微调该 Canvas 地形算法。
